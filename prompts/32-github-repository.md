# Commit or push to the repository

Use this when you want the working tree committed, pushed or cleaned up. The skill lists every uncommitted file, sorts each into code, notebooks, records, notes, sources or scratch, proposes `.gitignore` lines for the scratch, and waits for you to name what goes into the commit. Commit messages carry no Claude attribution. The skill runs only when you invoke it.

```
/github-repository
```
